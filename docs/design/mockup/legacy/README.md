# Edge 검토용 HTML 목업

`index.html`을 Microsoft Edge에서 열면 됩니다. 서버·빌드·외부 폰트·CDN 없이 동작하며 같은 폴더의 CSS와 JS 파일이 필요합니다.

초안 이미지가 현재 대화와 저장소에 없어 `../ux-spec.md`, `../UI/Designer.md`, `../../product.md`에 기록된 좌측 메뉴 / 중앙 카드 / 우측 업무·지시사항 배치를 바탕으로 작성했습니다. 원본 이미지와의 시각 일치 여부는 확인하지 못했습니다.

## 검토할 수 있는 항목

- BNOC 대시보드, 운영현황, CPCON·GPS 예시, 계급순 병력 카드, 야간 근무, 지시사항
- 정비 접수·작업 목록의 검색과 상태 필터, 요청 ID·작업 ID 구분, 읽기 전용 상세
- 정비 진행 내 목록·월간 캘린더 전환, 월 이동·일자별 일정 조회
- 정비 요청 입력·미리보기 (저장·전송하지 않음)
- 전시기 모드 전환, 키보드 탐색·대화상자 Escape 닫기, 좁은 화면 재배치, 인쇄 스타일

## Edge 표시 기준

Chromium 기반 Edge의 표준 HTML/CSS/JavaScript를 사용합니다. Windows 기본 글꼴 Segoe UI / 맑은 고딕, CSS Grid/Flex, 기본 dialog를 사용하며 실험적 API는 사용하지 않습니다. IE 모드는 대상이 아닙니다.

PC는 1440×900 또는 1920×1080, TV는 전시기 모드에서 1920×1080 / 3840×2160을 검토 기준으로 잡았습니다. 75인치 TV의 실제 해상도·배율·시청 거리는 미확인입니다. 전시기 모드를 켠 뒤 F11로 전체 화면을 전환할 수 있습니다. `index.html?display=tv`로도 전시기 모드를 시작할 수 있습니다. 좁은 창에서는 본문과 우측 패널이 세로로 재배치됩니다.

로컬 Edge 헤드리스에서 1440×1000 기본 화면과 1920×1080 전시기 화면을 캡처해 검토했습니다. JavaScript 구문 검사를 통과했습니다. 실제 TV·4K·터치 조작과 전체 상호작용의 자동 검증은 수행하지 않았습니다.

## 범위와 한계

모든 자료는 가상이며 표시 기준일은 2026-09-09입니다. 작업 6건(예정 1·작업 중 2·보류 1·조치 완료 2), 미완료 4건과 접수 대기 3건·종결 대기 1건은 서로 다른 집계입니다. 요청·작업·확인 여부를 합산하지 않습니다.

BNOC 화면 중심 목업입니다. 역할별 로그인·권한, 실제 접수·배정·종결, 업로드, 서버 저장, 실시간 연결, 기간별 실적·16시 보고, 일간·주간 캘린더는 구현하지 않았습니다. 정비 현황 화면은 현재 상세 등록 작업만 보여줍니다. CPCON·GPS 표시는 공식 운용 단계 확정이 아닌 시연 예시입니다.
