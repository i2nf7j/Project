# 알림·화면 테마·전시기 시연

- 우측 상단 알림: 요청 생성은 BNOC/관리자에게, 배정·재배정은 해당 부서 정비사에게 전달한다. 같은 부서에서 태그만 바꾸면 중복 알림을 만들지 않는다. 수신 계정으로 전환하면 새 알림 안내가 뜬다.
- 읽음은 시연 계정별로 저장하며 작업 확인·완료와 별개다. 알림을 누르면 접수 또는 작업 상세를 연다. 재배정으로 현재 권한을 잃은 작업 상세는 열지 않는다.
- 초기 샘플 요청은 새 알림으로 생성하지 않는다. 새 요청부터 알림이 쌓인다. 브라우저 저장 시연이며 서버·다른 PC 실시간 알림은 미연결이다.
- 다크/라이트 버튼은 우측 상단에 배치한다. 선택은 브라우저에 저장되며 편집 폼을 다시 그리지 않고 적용한다.
- 전시기는 일반 대시보드 확대 대신 전용 종합·운영현황·정비현황·근무자 화면을 사용한다. 일반 사이드 메뉴·엑셀 도구·하단 안내를 제거하고 종료 시 진입 전 화면으로 돌아간다. 1366×768, 1920×1080 기준 전체 페이지 스크롤 없이 배치한다. 긴 목록은 패널 내부 스크롤로 조회한다. 작은 모바일 화면에서는 세로 흐름을 유지한다.
- 상위 조회자 전시기는 비행단 가상 집계만 표시하며 로컬 병력·근무 명단은 제공하지 않는다.

검증: `node tests/experience.test.cjs`, `node tests/experience.browser.cjs` (Playwright 및 설치된 Edge 사용; TEST_BROWSER_PATH로 변경 가능).
